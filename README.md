# DevlStreak

> **Track your progress. Build your legacy.**

DevlStreak é uma plataforma que transforma a atividade de desenvolvimento em uma jornada visual de evolução. Inspirado na experiência do Strava e nas mecânicas de progressão de jogos, reúne estatísticas, streaks, XP, conquistas e metas em um hub interativo para desenvolvedores.

---

## 🧠 Visão do Produto

O GitHub fornece os dados — o **DevlStreak** transforma esses dados em **progresso e identidade**.

Desenvolvedores frequentemente têm dificuldade em:

- Visualizar sua consistência ao longo do tempo
- Reconhecer marcos e conquistas pessoais
- Transformar estatísticas técnicas em conteúdo visual interessante
- Encontrar motivação contínua para manter sua jornada de programação

O DevlStreak resolve isso reunindo tudo em uma experiência única, gamificada e compartilhável.

---

## 🎯 Proposta de Valor

Ajudar desenvolvedores a **visualizar sua consistência**, **reconhecer sua evolução** e **compartilhar sua jornada** de programação.

**Principal**

## ⚙️ Funcionalidades

### Perfil do Desenvolvedor

Cada usuário terá um perfil com:

- Nome, avatar e identificação
- Conta do GitHub conectada
- Nível atual e XP acumulado
- Streak atual e recorde pessoal
- Total de dias ativos
- Histórico de atividade
- Repositórios e linguagens mais utilizadas
- Conquistas desbloqueadas
- Cards e estatísticas selecionadas para compartilhamento

> Perfis públicos são opcionais, respeitando as configurações de privacidade.

### Statistics Hub

Dashboard principal com:

**Resumo geral**
- Streak atual e recorde
- Nível e XP
- Dias ativos
- Contribuições no período
- Meta semanal
- Conquistas recentes

**Histórico visual**
- Calendário de contribuições em estilo heatmap
- Atividade diária, semanal e mensal
- Comparação entre períodos
- Evolução de dias ativos e histórico de níveis

**Estatísticas exploráveis**
- Commits por período
- Repositórios ativos
- Distribuição de contribuições por repositório
- Linguagens utilizadas
- Atividade por dia da semana

### Gamification

- **Streaks** — dias consecutivos de atividade
- **XP & Níveis** — progressão contínua baseada em atividade
- **Conquistas** — marcos desbloqueáveis por comportamentos e metas
- **Metas semanais** — objetivos configuráveis pelo usuário

### Shareable Identity

- Cards de perfil personalizados
- Stickers de conquistas e streaks
- Compartilhamento para redes sociais
- Badges para uso em READMEs do GitHub

---

## 🛠️ Stack & Plataforma

- **Plataforma inicial:** Web app mobile-first, instalável como PWA
- **Fonte de dados principal:** GitHub API
- **Autenticação:** OAuth com GitHub

> O GitHub será a primeira fonte de dados, mas não define os limites futuros do produto.
